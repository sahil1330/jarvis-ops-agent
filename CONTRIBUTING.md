# Contributing

This hackathon repository uses pull requests for every change after the initial scaffold.

1. Create a focused branch.
2. Add or update tests.
3. Run `npm run check` and `npm run build`.
4. Open a pull request with the behavior, risk and verification notes.
5. Address Qodo findings before merge, or document why a finding does not apply.

Keep secrets and personal Google data out of commits, issues, pull requests and screenshots.
